# FinishLab

A no-gi BJJ position map: positions on Kesting's positional hierarchy, the sourced moves between them, and tools to study them.

Live at https://fisionr.github.io/finishlab/

This repository holds only the built site. Everything you save in the app (notes, plans, settings) stays in your own browser; nothing is sent anywhere. Moves are listed by published sources and are not instructor-reviewed.
